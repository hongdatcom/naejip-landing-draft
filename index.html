BEFORE YOU CALL

부르기 전에,
이런 걱정부터 드시나요?

급한 순간에도 작업을 이해하고 선택하실 수 있도록.

01

“뚫었는데 또 막히면?”

잠깐 물이 내려가는 것과 원인을 정리하는 것은 다를 수 있습니다. 반복되는 이유부터 살펴봅니다.

02

“큰 작업이 꼭 필요할까?”

고압세척이나 특수 장비, 배관공사가 꼭 필요한 것은 아닙니다. 현장에 맞는 방법을 설명합니다.

03

“비용이 투명할까?”

어떤 작업에 얼마가 드는지, 비용에 포함되는 범위를 먼저 설명합니다. 추가 작업이 필요하면 이유와 금액을 안내하고 확인을 받은 뒤 진행합니다.

01 / DIAGNOSE

어디서, 왜 생겼는지

고객이 겪은 증상과 현장 구조를 함께 확인합니다. 필요한 경우 내시경으로 보이지 않는 구간까지 살펴봅니다.

02 / EXPLAIN

왜 이 작업이 필요한지

장비 이름만 나열하지 않습니다. 현장 상태에 맞는 작업 방법과 범위, 비용을 이해하기 쉽게 설명합니다.

03 / CHECK

작업 후 무엇이 달라졌는지

물 빠짐과 역류 등 해당 증상에 맞춰 결과를 확인하고, 관리 시 주의할 점을 안내합니다.

내집처럼 살피고, 납득할 수 있도록 설명합니다.

QUESTIONS & ANSWERS

먼저 궁금한 것들.

상황을 알려주시면 확인 순서부터 안내하겠습니다.

이전에 뚫었는데 다시 막혔어요.

이전 작업 시점과 사용한 방법을 먼저 확인합니다. 이후 현장에서 배관 구조와 내부 상태를 점검해 정확한 원인을 파악하고, 왜 다시 막혔는지와 어떤 작업이 필요한지 설명드립니다.

사진만으로 비용을 알 수 있나요?

사진은 증상 파악과 작업 준비에 도움이 됩니다. 다만 안쪽 상태와 구조를 확인해야 하는 경우가 있어 최종 작업 범위와 비용은 현장 확인 후 안내합니다. 출장비는 없으니 방문 부담 없이 문의해주세요. 게임에서 쿠폰도 획득해보세요. 쿠폰별 사용 조건을 확인하실 수 있습니다.

모든 막힘에 필요한 것은 아닙니다. 막힌 원인과 범위, 배관 상태와 접근 조건을 확인해 적합한 작업 방법을 안내합니다.
